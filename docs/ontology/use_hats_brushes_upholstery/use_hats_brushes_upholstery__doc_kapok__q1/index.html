KAPOK: a name, in the Eastern archipelago for the cotton down enveloping the seeds of the silk cotton-tree, Bombax pentandrum. It is used by the poor inhabitants for stuffing chairs, pillows, &c., but is seldom or never used for beds, it being thought unwholesome to sleep upon.
