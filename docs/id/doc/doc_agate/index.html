Agate

popularly CORNELIAN (Ger. *achat*; Dutch, *achaat*; Fr. *agate*; Ital. *agata*; Russ. *agat*; Lat. *achates*). A genus of semi-pellucid gems, so called from the Greek *ἀγάτης*, because originally found on the banks of the river of that name in Italy. [J. R. McCulloch, Dictionary of Commerce and Commercial Navigation (1880), scan p. 58]
